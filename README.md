# 🧪 O Mistério do Laboratório Central

Desenvolvido para o Projeto Final da disciplina de Tecnologia e Programação.

## 🎯 Sobre o Projeto
Um jogo de história interativa em formato de página web onde o jogador toma decisões em tempo real para resolver uma emergência em um laboratório, explorando diferentes finais criados com lógica condicional (`if/else`).

## 🚀 Tecnologias Utilizadas
* **HTML5** (Estrutura da página)
* **CSS3** (Estilização e tema escuro)
* **JavaScript** (Lógica de decisões e
 interatividade)
* **CodePen & GitHub** (Desenvolvimento e hospedagem)

## 🎮 Como Jogar
1. Leia a situação apresentada na tela.
2. Digite uma das opções indicadas na caixa de texto.
3. Clique em **Enviar** (ou aperte **Enter**) para avançar na história e descobrir um dos 5 finais possíveis.
